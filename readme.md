# Tic Tac Toe

A two-player tic-tac-toe game in the browser. The board is a 3×3 grid. Players take turns placing **X** and **O**. The first to get three in a row (across, down, or diagonally) wins. If every square is filled with no winner, the game is a draw.

## Files

- `index.html` — page structure
- `styles.css` — layout and a small neutral palette
- `script.js` — turns, win/draw checks, and reset

## How to play

1. Open `index.html` in a browser.
2. X moves first. Click an empty square to place a mark.
3. After a win or a draw, choose **New game** to start over.

No build step or extra packages are required.
